# CampusFix Roadmap

## Project Vision

CampusFix aims to become a modern residence maintenance management platform that improves communication between students, technicians, administrators, and residence management teams.

The project continues to evolve through Agile development, peer collaboration, CI/CD automation, and open-source contribution practices.

---

# Current Features

The system currently supports:

- Maintenance request management
- Student request submission
- Repository layer implementation
- REST API services
- Swagger/OpenAPI integration
- CI/CD pipelines with GitHub Actions
- Unit and integration testing
- Agile backlog and sprint planning
- UML and Mermaid diagrams
- GitHub Project Board workflows

---

# Planned Features

## Student Features
